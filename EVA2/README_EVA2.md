# EduRAG Agent - Evaluación Parcial N°2

## Descripción

EduRAG Agent corresponde a la segunda etapa del proyecto EduRAG desarrollado para la asignatura Ingeniería de Soluciones con IA.

En esta evaluación se busca evolucionar el sistema RAG desarrollado anteriormente hacia un agente funcional capaz de utilizar herramientas, mantener memoria, recuperar contexto y tomar decisiones según las solicitudes del usuario.

## Objetivo

Desarrollar un agente académico capaz de apoyar a estudiantes de Duoc UC mediante consultas sobre documentación académica, utilizando herramientas de recuperación de información, memoria y planificación de tareas.

## Funcionalidades propuestas

- Consulta de documentos académicos mediante RAG.
- Uso de herramientas dentro del agente.
- Memoria de corto plazo.
- Memoria de largo plazo.
- Recuperación de contexto.
- Planificación de tareas.
- Toma de decisiones adaptativas.
- Generación de respuestas basadas en información recuperada.

## Tecnologías

El proyecto será desarrollado utilizando:

- Python
- Google Colab
- LangChain
- LangGraph
- Groq API
- Sentence Transformers
- FAISS
- PyPDF
